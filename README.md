# 🛒 Sales System — Bufe Otomasyon Sistemi

Kucuk olcekli isletmeler (bufe, kafe vb.) icin gelistirilmis satis yonetim uygulamasi.

## 📋 Proje Hakkinda

Bu uygulama, kucuk bir isletmenin gunluk satis islemlerini kolayca yonetebilmesi icin tasarlanmistir.

## 🛠️ Kullanilan Teknolojiler

- **Python** — Ana programlama dili

## 🚀 Nasil Calistirilir

```bash
git clone https://github.com/MucoX339/salessystem.git
cd salessystem
python main.py
```
